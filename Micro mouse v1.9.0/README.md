# Micro Mouse (v1.10.0)

## HW Environment
* **MCU:** STM32H533RET6
* **BOARD:** Custom PCB (Self-made)
* **MOTOR:** 1515RB 7.4v (Coreless Brushless Motor)
* **DRIVER:** DRV8316CRQRGFRQ1
* **SENSOR:** 
	* **IMU:** LSM6DS3TR-C (6-axis)
	* **IR:** IR26-21C/L110/CT
	* **PT:** PT26-21B/CT
	* **Encoder:** MT6701QT-STD (Magnetic)
	* **ToF:** VL53L4CX (Optional)
* **DISPLAY:** ST7735 0.96 LCD

## Dev Environment
* **IDE:** STM32CubeIDE 1.18.0
* **F/W Library:** STM32Cube FW_H5 V1.5.1
* **Debugger:** ST-Link V2
